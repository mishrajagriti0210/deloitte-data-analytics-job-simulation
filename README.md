# Deloitte Australia — Data Analytics Job Simulation

## Project Overview
A portfolio entry for the Deloitte Australia Data Analytics Job Simulation completed through Forage. This repository is intended to document the simulation work and the Tableau dashboard created as part of the experience.

## Project Focus
The simulation provided an opportunity to practise data analytics tasks in a business-oriented scenario and communicate findings through data visualisation.

## Tools
- Tableau
- Data analysis and visualisation

## Repository Contents
The following project artefacts are intended to be added:
- Tableau workbook or dashboard export
- Dashboard screenshots
- Supporting task files, where permitted
- Simulation certificate

## About the Simulation
This project represents a job simulation learning experience, not employment at Deloitte. The work and artefacts shared here should reflect the tasks completed during the simulation and must not include confidential or restricted materials.

## How to Review
Open the dashboard screenshot or Tableau workbook added to this repository. Refer to the supporting files for the specific task context and analysis.
